1. Extraia o pacote inteiro e mantenha as pastas e as bibliotecas juntas.

2. Abra `./tetrisphere` no Linux ou `tetrisphere.exe` no Windows.

3. Quando pedir, escolha o seu arquivo do jogo compatível. O jogo também encontra um arquivo compatível ao lado do executável ou aceita o caminho como último argumento da linha de comando. Formatos aceitos: `.z64`, `.v64`, `.n64` e `.zip`.

4. Mantenha a pasta `data/` ao lado do executável ao atualizar; ela guarda o arquivo importado, as configurações, o progresso e os diagnósticos. Mova ou copie a pasta inteira do jogo para levar os seus dados. Versões antigas guardavam os dados no seu perfil de usuário; para manter esse progresso, copie o conteúdo da pasta de dados antiga para a `data/` do jogo novo antes de abrir.

Abra **Options → Graphics** para as configurações gráficas e **Options → Controls** para remapear o controle. Use Apply para salvar as mudanças de controle. Reabra o jogo quando uma configuração pedir. Rode o jogo com `--help` para ver opções que valem para uma abertura só.

- Atalho · Ação

- F11 ou Alt+Enter · Alternar tela cheia

- F1 · Abrir ou fechar o inspetor do RT64

O inspetor traz controles seguros de filtragem ao vivo. As mudanças dele valem para a sessão atual; use Options para preferências permanentes.
