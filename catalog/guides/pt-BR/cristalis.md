Baixe a versão mais recente na [página de versões (Releases)](https://github.com/Claudio5702/Cristalis/releases/latest), e só de lá: `Cristalis-Setup.exe` para Windows, `Cristalis-linux-x86_64.tar.gz` para Linux.

1. Copie o jogo do seu console: a pasta `CRYSTAL DEFENDERS` (ou a pasta com o title id dele, `58410989`), como está no armazenamento do console, por exemplo num pen drive.

2. Com o instalador: coloque essa pasta ao lado do `Cristalis-Setup.exe` e abra. O jogo é instalado a partir dela, com atalhos e uma entrada na lista de aplicativos do Windows. Sem a pasta, a última janela do instalador pergunta onde ela está.

3. Compilado por você, sem o instalador: abra o `crystal_defenders.exe`. Na primeira abertura, ele pede essa pasta (ou uma pasta que já tenha `default.xex` e `Media`), ou usa direto se ela estiver ao lado do programa.

Os dados do jogo ficam então numa pasta `game` ao lado do programa; a pasta do console não é mais necessária. Guarde esses arquivos só para você.

Windows 10 ou 11, 64 bits, e uma placa de vídeo com Direct3D 11.

### O jogo a usar

- Title id · `58410989` (Xbox Live Arcade)

- Pacote do console · `58410989\000D0000\18F4739D37853F8596CE621540680922AFE9F23A`, 58.126.336 bytes, SHA-1 `118C64C901976CD8E2B570D77B0A5E01C15C7A46`

- `default.xex` dentro dele · 1.658.880 bytes, SHA-1 `31A90704D4233F6E730714515CD5F20BF08D7F0D`

O programa confere se o `default.xex` é o mesmo de onde o código foi traduzido e avisa quando não é.
