1. Baixe o pacote para o seu sistema na [página de versões (releases)](https://github.com/bertibertig/SSX3-Recomp/releases) e extraia.

2. Coloque os arquivos do seu jogo na pasta `game_files/` usando o instalador:

- **Windows:** clique duas vezes em `install_game.bat` (ele roda o `install_game.ps1`)

3. Abra o jogo pelo script do launcher:

- **Windows:** clique duas vezes em `run.bat` (ele roda o `run.ps1`)

Se a pasta `game_files/` ainda estiver vazia, o launcher abre o instalador sozinho e depois segue para o jogo (`SSX3_INSTALL=0` desliga isso).

```
sudo apt install libsdl2-2.0-0 libssl3 libepoxy0 mesa-vulkan-drivers
```
