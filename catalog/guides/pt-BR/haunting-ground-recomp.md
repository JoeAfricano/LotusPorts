- PS2 · Teclado (padrão) · Controle

- Direcional · setas · direcional

- Analógico esquerdo · I J K L · analógico esquerdo (o direito também funciona)

- X / Círculo / Quadrado / Triângulo · X / C / Z / S · os mesmos botões (PlayStation) ou A / B / X / Y (Xbox)

- Start / Select · Enter / Shift direito · Options / Create (ou clique no touchpad) no PlayStation, Menu / View no Xbox

- L1 / R1 / L2 / R2 · Q / E / 1 / 3 · os botões de ombro e gatilhos

**F11** alterna entre janela e tela cheia, **F3** mostra a sobreposição de velocidade e **Esc** sai.

Controles DualSense, DualShock 4 e Xbox funcionam por USB ou Bluetooth. A vibração do jogo chega ao controle, e a barra de luz do DualSense fica num âmbar fraco (os dois podem ser mudados). O primeiro controle a apertar um botão é o jogador um. Se a Steam estiver aberta com o "Suporte a controle de PlayStation" ligado e o controle agir como um de Xbox, veja [docs/controller.md](https://github.com/N900x4/HauntingGround-Recomp-Project/blob/HEAD/docs/controller.md), na parte "Steam Input".
