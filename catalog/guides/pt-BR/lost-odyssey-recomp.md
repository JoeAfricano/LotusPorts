Baixe o pacote para o seu sistema na [versão mais recente](https://github.com/freefrank/LostOdysseyRecomp/releases/latest).

- Windows x64: `LostOdysseyRecomp-windows-x64-<versão>.zip`. Extraia o ZIP inteiro numa pasta em que você possa gravar e abra o `LostOdysseyRecomp.exe`. Precisa de um processador com AVX.

1. **Importe os dados do jogo.** O importador abre quando nenhum jogo é encontrado. Escolha uma pasta com o jogo extraído, o `default.xex`, uma ISO ou dados GOD.

2. **Obtenha os shaders.** Na primeira vez, o jogo oferece shaders pré-compilados para o seu renderizador; se você pular, ele os compila uma vez.

3. **Adicione os outros discos e os DLCs** em Settings → **System → Import discs & DLC**. Com os quatro discos importados, o jogo troca de disco sozinho.

O disco 1 é obrigatório para começar. Use um conjunto de quatro discos aceito (asiático multilíngue ou EUA/Europa) e não misture edições; o [guia de instalação](https://github.com/freefrank/LostOdysseyRecomp/blob/HEAD/docs/INSTALLING.md) mostra como conferir o seu.

### HDR

Ligue o **HDR** em Graphics e salve. **HDR peak brightness** abre uma página de calibração; **LB / RB** alternam entre a cena do jogo e uma imagem de teste.
