Para compilar ou testar localmente, o projeto espera os dois discos americanos (USA) nestes caminhos:

```
disc/Disc1/Valkyrie Profile (USA) (Disc 1).cue
disc/Disc2/Valkyrie Profile (USA) (Disc 2).cue
```

A pasta `disc/` fica de fora do Git de propósito.
