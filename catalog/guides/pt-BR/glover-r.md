A versão atual é a **1.0.1**. Baixe o pacote para o seu aparelho na seção de versões (Releases) do GitHub e siga os passos abaixo.

- Aparelho · Pacote · Como abrir

- Windows x64 · `Glover-R-1.0.1-Windows-x64.zip` · Extraia o ZIP e abra o `Glover-R.exe`. Mantenha as DLLs e os arquivos de dados ao lado dele.

O **Release Bundle** reúne todos esses, o Mod SDK e a Modern Camera. No Steam Deck, use o pacote **x86_64**.

Você precisa do seu próprio arquivo **americano (USA)**, sem modificações. Escolha no launcher e clique em **Play**. O jogo e os arquivos originais dele não vêm junto.

Arquivo aceito: USA, revisão 0, código do jogo `NGVE`, 8 MiB. O launcher aceita as ordens de bytes `.z64`, `.n64` e `.v64`. O SHA-1 canônico é `270be17b3c8da9b88a7b99c2a545b0bce16837f4`.
