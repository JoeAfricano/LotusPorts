1. Baixe o `LetsGoRecomp-<version>-windows.zip` na página de [versões (Releases)](https://github.com/raulzrrs/letsgo-recomp/releases) e extraia numa pasta onde dê para gravar.

2. Abra o **`LetsGoRecomp.exe`** (se o Windows avisar, **Mais informações** → **Executar assim mesmo**).

3. Na página **Game**, clique em **Select game folder...** e escolha a pasta que tem `exefs` e `romfs`.

4. Espere enquanto ele copia os arquivos e recompila o jogo para o seu PC (só uma vez: 22 minutos num processador de 20 threads, mais com menos threads).

5. Clique em **Play**.

Tudo fica nessa pasta (configurações, saves, mods). Para atualizar, extraia uma versão nova por cima. Para os dois jogos, use uma pasta para cada.
