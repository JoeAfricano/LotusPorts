1. Rode o instalador, ou o `StrikeCollectionHD.exe`. Indique os seus arquivos dos jogos; eles são copiados para `%APPDATA%\DesertStrikeHD\DesertStrikeHD\roms\`.

2. Escolha um jogo. **Settings** na tela de escolha, ou **Esc / Back** no jogo, abre o menu.

- Mega Drive · Teclado · Controle

- Direcional · Setas / WASD · Direcional / analógico esquerdo

- A / B / C · J K L ou Z X C · Oeste / Sul / Leste

- Start · Enter · Start

Atalhos:

- **F5 / F7:** salvar / carregar rápido.

- **F11** ou **Alt+Enter:** tela cheia.

- **Tab** ou **gatilho direito:** acelerar.

- **Q / E** ou **LB / RB:** passar pelos objetivos no minimapa.

- **Backspace** ou **gatilho esquerdo** (segurar): voltar no tempo.

- **Shift esquerdo** ou **Y** (segurar): deslocamento lateral, o "segurar A" do Desert Strike, sem disparar um Hellfire. Aperte A durante o deslocamento para disparar um Hellfire e continuar. O analógico direito também desloca (esquerda ou direita). **Strafe Speed** (Settings > System) pode deixar o deslocamento 1,5x ou 2x mais rápido.

- **M**, ou segurar **Esc / Back**: mostrar ou esconder o minimapa.

- **Esc** ou **Back:** menu de pausa.

Tudo pode ser remapeado em **Controls**.

**Edição Amiga:** Settings → Audio → **Add Amiga Disks** e escolha os seus arquivos `.adf` do Desert Strike de Amiga (eles são copiados para `%APPDATA%\DesertStrikeHD\DesertStrikeHD\amiga\`). Nada da versão Amiga vem junto. Veja `docs/13-amiga-ultimate.md`.

**Gráficos HD:** Settings → System → **Build HD Pack**, uma vez por jogo. Leva alguns minutos. Veja `docs/09-hd-packs.md`. No Linux, escolha o renderizador em Settings → Display → **Renderer (restart)**. OpenGL (placa de vídeo) é o padrão; ligue **Show FPS** para ver o renderizador ativo. A renderização por software continua disponível como alternativa.
