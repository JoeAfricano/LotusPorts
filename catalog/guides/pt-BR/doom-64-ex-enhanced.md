Depois de compilar e com os arquivos de dados no lugar certo, é só abrir o executável:

- **Windows:** clique duas vezes no `DOOM64EX+.exe`. Se quiser mais opções de configuração, use o `DOOM64EX+ Launcher.exe`, que é opcional.

- **Placas NVIDIA:** se o jogo engasgar, é muito recomendado desligar o VSync deste aplicativo no Painel de Controle da NVIDIA.
