### Para jogadores

1. Baixe o zip para Windows ou o AppImage para Linux na página de [versões (Releases)](https://github.com/monscriser/UFC3MONS/releases).

- O zip para Windows tem só `Launcher-Config.exe`, `UFC3.exe` e `data/`. Cada arquivo tem um `.sha256` para conferir.

2. Abra o launcher e indique o **seu próprio** jogo: pasta Reborn, XEX/pasta original ou ISO.

3. Opcional: instale DLC a partir de uma pasta, escolha resolução/FSR 1 e idioma, ou use **Add to Steam**.

4. Clique em **PLAY**.

**Requisitos:** uma placa de vídeo com Vulkan e um processador com SSE4.2 (x86-64-v2). **Não precisa de AVX2.**

O botão **Download ZIP** do GitHub baixa o código-fonte, não um jogo pronto. Nenhum dado do jogo, DLC ou save vem junto.
