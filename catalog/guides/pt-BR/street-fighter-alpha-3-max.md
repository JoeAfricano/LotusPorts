Os controles, modos e opções (inclusive as extensões):

- Teclado · PSP · Controle

- Setas · Direcional · Direcional ou analógico esquerdo

- Z / X / A / S · X / Círculo / Quadrado / Triângulo · Sul / Leste / Oeste / Norte

- Q / W · L / R · Botões de ombro

- E / R · L2 / R2 (acrescentados) · Gatilhos

- Enter / Backspace · Start / Select · Start / Back

- F2 · Volta na hora ao MODE MENU, sem salvar (só teclado)

- F11 ou Alt+Enter · Tela cheia liga/desliga (o jogo abre em tela cheia; `--windowed`, ou desmarque Full screen no launcher, para janela)

- Alt+F4 (Windows), Cmd+Q (macOS), Ctrl+Q (Linux) ou o botão de fechar da janela · Sair (como qualquer programa; o Esc não sai mais)

- Jogadores, entrar no meio e os modos de rede num mesmo PC: [docs/PLAYERS.md](https://github.com/theweathervane/sfa3max-decomp/blob/HEAD/docs/PLAYERS.md)

- Controles e ícones dos botões: [docs/CONTROLLERS.md](https://github.com/theweathervane/sfa3max-decomp/blob/HEAD/docs/CONTROLLERS.md); botões: [docs/PLAYER_CONFIG.md](https://github.com/theweathervane/sfa3max-decomp/blob/HEAD/docs/PLAYER_CONFIG.md)

- VSYNC e FRAME TIMING (AUTO, o padrão, escolhe SMOOTH numa tela de 60, 120, 240 Hz... e ORIGINAL, o 59,94 Hz do PSP, com VRR ou outras taxas; o MODE MENU mostra qual foi escolhido): [docs/DISPLAY.md](https://github.com/theweathervane/sfa3max-decomp/blob/HEAD/docs/DISPLAY.md)

- Saves e configurações (`saves/sfa3max.cfg`, `saves/sfa3max.dat`; arquivos de versões anteriores, `sfa3mr.cfg` / `sfa3mr.dat`, são renomeados na primeira abertura): [docs/SAVES.md](https://github.com/theweathervane/sfa3max-decomp/blob/HEAD/docs/SAVES.md)

- **Extras escondidos** (todos liberados): segure **L + R** ao confirmar Dramatic Battle, Variable Battle, R.Dramatic Battle ou Final Battle no MODE MENU para a versão alternativa; segure **SELECT** ao escolher Akuma (Shin Akuma), M. Bison (Final Bison) ou a segunda vaga do Balrog.

- **Sem as extensões**, como o programa do PSP sozinho (menus e saves próprios, um controle): `build/sfa3max --work work --no-extensions`, ou compile assim com `build.cmd --no-extensions` / `./build.sh --no-extensions`: [docs/BUILDING.md](https://github.com/theweathervane/sfa3max-decomp/blob/HEAD/docs/BUILDING.md#without-the-extensions)
